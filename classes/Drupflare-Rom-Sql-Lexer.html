\Drupflare\Rom\Sql Lexer

A byte-oriented MySQL lexer.

Every byte of the input lands in exactly one token, whitespace and comments included, so the token texts concatenate back to the input. Malformed input never throws: it becomes an Error token and lexing carries on, so a statement the translator does not understand is refused by name later instead of vanishing here. Nothing here uses mbstring; bytes 0x80 to 0xFF are identifier bytes, which is how MySQL treats multibyte names.

Placeholders are not special. wpdb finishes the SQL before it reaches this class, so a question mark is an operator byte and a colon name is an operator followed by an identifier.

splitStatements()

splitStatements(string  $sql) : list<string>

Splits a script into statements at top-level semicolons.

A scanner rather than a split on a semicolon, because a semicolon inside a string, a quoted name or a comment is not a boundary. Comments are dropped and leave one space behind, so the words on either side do not fuse; executable comments stay, because MySQL runs their contents.
